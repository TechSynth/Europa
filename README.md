# EUROPA - Creative Production House

> **Live Demo:** [Click here to view the website]()

A minimalist web platform designed for a creative production company with offices in Madrid, Barcelona, and Berlin.

## Project Overview
This project focuses on building a high-end visual experience for showcasing audiovisual talent. It is currently a Work in Progress (WIP), transitioning from design concepts to a fully functional web application.

## Tech Stack
* **HTML5 & CSS3:** Semantic structure and custom styling.
* **Vanilla JavaScript:** Custom carousel logic and dynamic menu systems with randomized color palettes.
* **UI/UX Design:** Prototyped in Figma to ensure a pixel-perfect transition to code.

## Roadmap & Upcoming Features
* **Talent Portfolios:** Expanding the Directors and Photographers sections with dedicated profiles.
* **Work Gallery:** Implementing a grid-based video/image showcase for the Work section.
* **Dynamic Content:** Future integration of a backend or CMS to manage the roster.
